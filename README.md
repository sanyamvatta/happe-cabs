# Happ E Cabs Website

Static GitHub Pages-ready website for Happ E Cabs.

## Files

- `index.html` - main landing page
- `investors.html` - Investors & Network Partners coming soon page
- `styles.css` - complete responsive styling
- `script.js` - booking, animations, calculator, and UI behavior
- `assets/` - SVG visual assets

## Deploy on GitHub Pages

1. Push these files to a GitHub repository.
2. Open repository Settings.
3. Go to Pages.
4. Select the branch and root folder.
5. Save. GitHub will publish the static site.
